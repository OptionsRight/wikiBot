# 22：向获准群受众回答并安全引用历史

**What to build:** 只有群受众可核验且全部有资格时提供群答案，引用历史答案不带出个人上下文、未交付内容或失效正文。

**Blocked by:** 18：模型变更暂停服务并标记历史答案。

**Status:** blocked

**交付阶段：** 完整范围。依据为 2026-09-26 两轮访谈修订后的 wikiBot v0.4，设计约束及任务拆分已由用户的 implement 指令确认。

**用户故事：** US-34、US-45、US-46（实施规格编号）。

**外部前提：** 任务 02 证明可用的群受众接口、获准测试群、成员变更测试条件；条件不满足则保持禁用并记录阻断。

## Acceptance criteria

- [ ] 每次群问答和实际交付按当前群受众检查领域资格；成员范围未知/变化后不满足条件时停止群答案并引导认证个人入口。
- [ ] 同领域可见不意味着可查看其他人的私人答案；群会话与私人上下文隔离，引用必须匹配原受众和允许已交付范围。
- [ ] 模型待复核历史引用显著标记，未交付/unknown 正文不经群引用补发；知识撤回和确认错误优先阻断正文。
- [ ] 群内维护请求转认证个人入口，草稿、来源材料、工单内部内容不发布到群；按钮执行再次校验身份/能力/版本。
- [ ] 群会话序列化、重复入站、累计交付、deadline 与未知回执沿用已验证共享契约，不创建独立权限或问答状态机。
- [ ] 真实群演示成员加入/退出、未知目录、引用他人答案、私人追问、撤回及模型待复核；保留可核对交付证据。

## 验证方式

公开业务入口授权组合测试及真实群协议联调；扩展 A-02、C-01、M-02 的群受众边界。

验收结果须记录实际配置/版本、执行环境、预期与实得、证据及剩余阻断；未实现、未运行或外部前提缺失不能标为通过。用例集中于公开业务行为和真实适配契约，避免为内部实现细节建立镜像测试。

## 范围边界

未能核验全部受众的群不启用，不通过提示用户自律替代服务端授权。
