# 07：网页自由文本问答与版本化引用

**What to build:** 成员在网页自由文本提问，得到基于已发布页面的回答、当前状态和可核对的固定版本引用。

**Blocked by:** 06：发布首个检索式知识版本并供成员浏览。

**Status:** in-progress

**交付阶段：** 试点。依据为 2026-09-26 两轮访谈修订后的 wikiBot v0.4，设计约束及任务拆分已由用户的 implement 指令确认。

**用户故事：** US-11、US-14、US-15、US-24（实施规格编号）。

**外部前提：** 受控测试身份和页面/金样例可先验证机制；真实业务样本、公司身份和专家批准须另行取得。

## Acceptance criteria

- [ ] 请求固定发布描述、模型、检索、模板及偏好快照；装配期间版本切换不能混用新旧知识。
- [ ] 受限检索加一次模型调用组织回答；引用必须来自本次实际检索页面，禁止协议失败后自动挂首篇引用伪造依据。
- [ ] 模型正文经过协议、引用和当前有效性校验后持久化并外发；未经校验的增量、thinking 或协议残片不可泄露。
- [ ] 关键事实和步骤由金样例及专家核验，引用合法不等于语义正确；不再要求程序清单或结构性穷尽证明。
- [ ] 答案/作业持久化、幂等、重连、期限及失败原因保持真实；取消或截断不改算成功简答。
- [ ] 公开网页验证自由文本、术语/单步问答、无命中、错误引用、模型失败、取消和引用展开；空占位不计有用首段。
