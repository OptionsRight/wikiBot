## Acceptance criteria

- [ ] 可信消息经同一业务服务和入站事务执行，以真实稳定消息 ID 去重；同文本不同消息独立，当前领域资格、对象范围和固定描述始终生效。
- [ ] 每 bot 一个连接拥有者，失去归属的旧网关不能发送；重连按已验证策略恢复，不宣称无缝多实例接管。
- [ ] 只发送通过校验的累计正文，同一流至多一个未确认更新；旧/迟到回执不覆盖新内容，最终正文及最终回执共同决定完成。
- [ ] 按 UTF-8 字节校验预算；超限转认证网页并明确企微正文未完整交付，不能以网页链接送达计原企微完整成功。
- [ ] 外发前再核验授权、知识撤回与模型资格；回执丢失为 unknown，状态/通知重试不重复创建答案或其他业务结果。
- [ ] 用户能明确取消、查看失败/不完整原因，可信映射下本人风格偏好与网页一致；未映射身份不能取得私人网页历史。
- [ ] 真实租户演示连续块、滚动重启、重复入站、长正文、回执迟到/丢失和知识失效后的排队消息。
