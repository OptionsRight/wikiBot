# 已知模型变化后优先使用经过验证的组合

2026-09-26 设计访谈 Q4 已确认：公司模型部署或别名已知发生变化时，暂停受影响的新生成及依赖旧评估的候选激活，重新验证并发布配置后恢复；经过验证的替代配置也须通过发布流程切换。该选择接受短期生成不可用，以避免未经评估的模型继续承接原有质量与容量承诺；模型变化本身不等于知识版本已撤回，也不假定能发现供应方全部未公开变化。

同日 Q7 确认已经交付的受影响历史答案仍可查看，并显著标记“模型验证待确认”；尚未发生的主动投递暂停，无法确认模型资格的进行中回答停止并保留失败或不完整记录。保留历史可见性是为了让用户仍可追溯已收到的信息，不代表重新批准答案质量；后续确认错误或知识撤回时执行相应失效与更正，新的模型回归通过也不自动证明过去的具体答案正确。
