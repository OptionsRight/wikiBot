# 首版流程分支采用互斥的完整路径

2026-09-26 设计访谈 Q1 已确认：首版每个流程分支表示一条互斥的完整操作路径，只有恰好命中一个分支时才能输出操作清单。零命中区分不适用和知识未覆盖，多命中属于结构冲突，不能通过选择第一条或合并步骤继续回答。该选择限制了可叠加规则的表达，但使必要步骤的计算和完整性验收有唯一依据；未来引入组合规则时必须重新设计其语义及知识迁移。

同日 Q5 确认可以先发布由负责人明确批准的有限支持范围，但范围内各路径必须完整且不能有分支空洞；范围外透明报告知识未覆盖。支持范围随知识版本复核并在验收前固定，不能通过测试后缩小范围掩盖失败。
